# Separate computation from intelligence

Trace the unary-increment Turing machine from the teaching note on inputs `11_` and `_`. Record the state, head position, scanned symbol, written symbol and next state at every step. Predict final tapes `111` and `1`. Explain why the machine halts for these valid inputs and what would happen if a transition were missing for an unexpected symbol.

Run `python3 code/turing/solution.py` to compare the original simulator's output with your trace. This activity is a Higher Level extension. All learners should explain why a Turing machine and a Turing test are different concepts. Connect one historical development to a change in capability rather than reciting an isolated date.
