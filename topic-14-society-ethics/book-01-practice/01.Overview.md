# 2. Practise: Society

Check an app claim and recommend a next step.

**Core time: 35–45 minutes.** You need paper or a document. No AI account, survey or coding is needed. Finish with one small table and a five-sentence recommendation. The Turing trace is an optional Higher Level task.

## The proposal

A fictional school library wants an app that recommends books using borrowing history. The supplier claims “95% accuracy” but gives no test details. New readers have little history. Readers can ignore recommendations, but the proposal does not explain how long records will be stored.

1. Write the decision: “Should the school try this app?”
2. Name three stakeholders: a regular reader, a new reader and a librarian.
3. For each, write one need. For example, “A new reader needs useful suggestions without a borrowing history.”

**Checkpoint:** you have three people/groups and three needs. You are ready for **Investigate**. If a term is unfamiliar, return to <a href="https://tutors.dev/note/lc-cs/topic-14-society-ethics/note-01-learn">1. Learn</a>.
