# Audit evidence against requirements

Create a table mapping each requirement to a code location, test and demonstration. Identify missing evidence before adding features. Use the four ALT descriptions to check that your portfolio includes database retrieval, a data investigation, a model experiment and embedded input/output work. Explain whether any hardware evidence is simulated.

Select one defect or limitation with a clear user consequence. Write an acceptance test for the improved behaviour and record the current failure. Estimate the smallest change that solves it. In your group, assign and rotate responsibilities; each person keeps an individual explanation of the design and their own contribution. Keep collaborative practice separate from any individually assessed coursework that is in progress.
