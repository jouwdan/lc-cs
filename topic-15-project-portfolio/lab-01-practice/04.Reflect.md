# Explain and assess independently

Give a three-minute explanation without reading the source line by line. Describe the inputs, data representation, main algorithm, one test and one limitation. A partner asks what would happen if an input changed. Answer by reasoning, then verify with a test.

Apply the original five-category classroom rubric and cite evidence for each score. Write 200 words covering what changed after feedback, what you understand better, and what you would improve next. For coursework preparation, list the details that must be taken from the current SEC brief rather than this practice course. Submit the portfolio index, test record, iteration evidence and individual reflection. Keep genuine failures visible when they explain learning.
