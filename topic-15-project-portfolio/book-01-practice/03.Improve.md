# Improve and retest

Change one thing and check its effect.

1. Make your planned change. Keep the earlier version.
2. Run the test that exposed the issue, then one test that passed before. Record exact results.
3. Write three lines: **Before … / I changed … because … / Retest showed …**.
4. Demonstrate the main task and one boundary or failure case. A screenshot plus a short explanation is enough for this practice record; show actual behaviour.

**Example:** “Before: an empty list caused division by zero. I added the specified empty-input result before division. Retest: empty input was handled and `[4,6,8]` still returned 6.” Your own contract must define what empty input should do.

**Checkpoint:** the evidence shows what changed and whether it helped. If the issue is unresolved, record the current result and the next small test; do not claim a pass. Continue to **Reflect**.

**Optional HTML extension:** make an index page linking the evidence. Copy the whole folder elsewhere and open it there. Fix broken links or media paths. Use readable text, captions or narration for demonstrations. This is report practice, not an official submission template.
