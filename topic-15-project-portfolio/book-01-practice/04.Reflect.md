# Explain your work

Describe your contribution and next step.

1. Give a one-minute explanation: input → main process → output. Include one test and one limitation. If alone, say it aloud or write four sentences.
2. Predict what would happen for a changed input, then run that test.
3. Complete: “My contribution was …”; “One thing I now understand is …”; “My next small improvement is …”.
4. Use the <a href="https://tutors.dev/note/lc-cs/topic-15-project-portfolio/note-01-learn">20-point practice rubric</a>. Give each score a piece of evidence. Choose one area to improve; the score is feedback, not an SEC grade.

**Done:** you have a short start page, design/requirements, code/data, test-and-change record and reflection. Another learner should be able to find and run the work without guessing filenames.

**Optional coursework preparation:** with your teacher, list the features, files, report format, dates, allowed help and authentication conditions in the relevant SEC brief. Keep that list separate from this practice folder: our suggested headings are not official requirements.
