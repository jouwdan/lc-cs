# 2. Practise: Projects

Improve one artefact and keep the evidence.

**Two sessions of about 40 minutes.** Organise one artefact you already tried in Topics 10–13. You need its code/results and a folder or document. You do not need four completed ALTs.

1. Pick one: data analysis, queue model, indicator or database search.
2. Write its user need in two sentences. Example: “A librarian needs a clear message when no title matches. The current search sometimes leaves old results visible.”
3. Create sections named **start here**, **design**, **code/data**, **tests** and **reflection**. Use these as headings in one document if that is easier.
4. State what you made yourself and what came from a starter example or teammate.

**If you have no artefact yet:** return to one <a href="https://tutors.dev/lab/lc-cs/topic-10-data-analytics/book-01-practice">Topic 10 lab</a>, <a href="https://tutors.dev/lab/lc-cs/topic-11-modelling-simulation/book-01-practice">Topic 11 lab</a>, <a href="https://tutors.dev/lab/lc-cs/topic-12-embedded-systems/book-01-practice">Topic 12 lab</a> or <a href="https://tutors.dev/lab/lc-cs/topic-13-information-systems/book-01-practice">Topic 13 lab</a>. Complete its core task first. Watching a solution is not the same as doing the work.

**Checkpoint:** you have one chosen artefact and a place to keep evidence. Continue to **Plan**. This is collaborative classroom practice; it is separate from individual assessed coursework.
