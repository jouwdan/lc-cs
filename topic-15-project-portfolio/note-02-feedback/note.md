## Question 1

**Answer: They are collaborative learning contexts; coursework is a separate individual assessment.** ALTs let you learn with others. The assessed project has its own brief and rules for showing the work is yours.

## Question 2

**Answer: Display a no-match message when a search returns no records.** You can search for an absent title and check whether the message appears.

## Question 3

**Answer: Input/setup, expected and actual results, outcome and action.** Another person should be able to repeat the input and understand the result. Keep failures and retests too.

## Question 4

**Answer: Revisiting and improving a design using feedback and tests.** You try a version, use feedback and improve it. You still plan and test.

## Question 5

**Answer: A query whose records are displayed through an interaction.** Show the database tables, the query and the records displayed. A list typed into HTML does not prove a query ran.

## Question 6

**Answer: False.** Passing software tests does not prove the wires, voltages or physical sensor readings are correct.

## Question 7

**Answer: The relevant SEC brief and applicable official instructions.** Read the brief for the project you are actually completing. Do not copy deadlines or formats from a practice task.

## Question 8

**Answer: A failed boundary test revealed a condition error; after changing it, the boundary and earlier tests passed.** It tells the reader what went wrong, what changed and which tests passed afterward.

## Question 9

**Answer: An original formative classroom rubric.** Use it to choose an improvement. It is not an official marking allocation.


## Portfolio checkpoint

A complete small practice record has **one** chosen artefact, two requirements/tests, a saved earlier version, one change/retest and a short explanation of your contribution. The artefact may still have a limitation if you describe it honestly.

Example reflection: “I changed the no-result branch to clear old results and display a message. The absent-title test now passes, and a normal title still returns a match. I wrote that change; the initial database example came from the course. I still need to check how the page behaves on a narrow screen.” This explains more than “everything worked”.
