## Question 1

**Answer: A variable held only in RAM.** Ordinary RAM is volatile; saving persistent data is a separate action.

## Question 2

**Answer: ALU.** The ALU performs arithmetic and logical operations; the control unit coordinates them.

## Question 3

**Answer: The next instruction address.** A branch can change the next address. The PC does not store the entire program.

## Question 4

**Answer: Allocating CPU time to programs.** Scheduling shares execution resources between tasks.

## Question 5

**Answer: Touchscreen.** The screen displays information while touch sensing receives user input.

## Question 6

**Answer: Assembler.** An assembler converts symbolic machine instructions into machine code.

## Question 7

**Answer: The source can be translated under the translator rules.** Logic faults can remain after syntax checks and translation succeed.

## Question 8

**Answer: Tasks that can be divided may benefit.** Sequential dependencies and overhead limit parallel speed-up.

## Question 9

**Answer: A document editor.** An editor serves a user task; the other options are hardware.
