# Draw the parts

Label input, processing, output and storage.

## 1. Copy this starting diagram

```text
Scanner → Loan program → Screen
                ↕
          Saved loan records
```

Arrows show data moving between parts.

## 2. Add four labels

Label the scanner **input**, the CPU running the program **processing**, the screen **output**, and the saved records **storage**.

Add a printer. Draw an arrow from the program to it. Label it input or output.

**Check:** the printer is output. It receives the due date to print.

## 3. Choose where the data goes

| Item | RAM or saved storage? |
|---|---|
| A book code being checked right now | … |
| A loan record kept for next week | … |

**Check:** working values use RAM; the lasting record is saved to storage. Explain what would happen if power failed before the record was saved.

## 4. Optional extension

The catalogue is on another computer. Add a network connection and a server to your diagram. Draw a request for the book record and a response.

**Check:** the network carries the request and response; it does not replace the CPU or saved storage.
