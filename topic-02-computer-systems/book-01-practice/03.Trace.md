# Trace

Trace the simplified machine instructions LOAD 9; ADD 3; STORE count; HALT. Make columns for instruction, working register and count. Before STORE, count has not yet received the result; after STORE it contains 12. Explain why the ALU and control unit have different jobs.

Higher Level: add a branch that skips printing if count is zero. Identify which component determines the next instruction address. Do not invent a machine instruction syntax and present it as Python.
