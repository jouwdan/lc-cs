# Trace instructions

Follow four instructions one at a time.

A **trace** records what changes after each instruction. This is an invented machine, not Python.

## 1. Complete the table

`LOAD` puts a number in the working register. `ADD` increases it. `STORE` copies it to a named main-memory location. This is not saving a file to disk; the value is still working data. `HALT` stops.

| Instruction | Working register afterwards | Memory value `count` |
|---|---:|---|
| LOAD 9 | 9 | Not set |
| ADD 3 | … | Not set |
| STORE count | … | … |
| HALT | … | … |

## 2. Check your trace

After `ADD`, the register is **12**. After `STORE`, the memory value `count` is **12**. `HALT` does not change either value.

The **ALU** performs the addition. The **control unit** coordinates the instructions.

## 3. Try a fresh example

Use `LOAD 4; ADD 5; STORE count; HALT`.

**Check:** the memory value `count` is **9**. If yours differs, check one row at a time.

## Higher Level extension

Suppose the next instruction depends on whether `count` is zero. Which register holds the next instruction's address?

**Check:** the **program counter**. The address is different from the calculated count. A branch changes the instruction sequence.
