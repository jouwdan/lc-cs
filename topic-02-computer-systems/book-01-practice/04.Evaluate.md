# Explain your choices

Choose hardware and explain two OS jobs.

## 1. Choose storage

A library worker carries a laptop between rooms. Compare an SSD and HDD using **movement**, **access speed** and **cost**. Write two or three sentences.

**Example answer:** “An SSD has no moving read head, so it suits a laptop carried around. It usually gives faster access. An HDD may provide more capacity for the same price.”

## 2. Explain two OS jobs

Finish these sentences:

- “When the station prints a receipt, the OS…”
- “When it saves a loan record, the OS…”

**Check:** it controls the printer through a driver and manages the file operation. Other relevant services include allocating memory and sharing CPU time.
