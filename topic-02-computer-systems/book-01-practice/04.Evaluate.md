# Evaluate

Compare an SSD and a hard drive for a mobile library laptop using portability, access speed and cost as criteria. Explain two OS services used when scanning and printing. Model answer: a driver controls the scanner/printer; scheduling shares processor time; memory management allocates working data; file management stores records with permissions.

Peer-review checklist: role labels correct; RAM/storage distinction explicit; trace gives 12; two choices justified by user needs. Revise any claim that a single specification, such as clock rate, proves the whole system is faster.
