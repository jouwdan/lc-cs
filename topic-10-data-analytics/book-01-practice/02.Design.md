# Design the cleaning and summaries

Write pseudocode with separate steps for reading, validation, grouping and summarising. Accept finite values between 0 and 120 inclusive for this practice dataset. Reject blank or non-numeric values with a reason. Do not convert them to zero. Record the row number of each rejection so another learner can reproduce the result.

Manually calculate the count, mean, median and all tied modes for `4, 6, 6, 12`. Specify the result for an empty list. Design tests for unsorted values, an even length, an odd length, repeated values, a single value and no values. Explain why testing only a sorted five-item list would miss an important error. **Higher Level:** justify preserving original ordering and compare a sort-based median with alternatives without overclaiming efficiency.
