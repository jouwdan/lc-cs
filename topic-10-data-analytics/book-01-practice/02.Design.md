# Predict one change

Change one input and predict its effect.

Keep `my_readings.py` open. The first line containing `values =` is the data for your experiment.

1. On paper, sort `9, 1, 3, 3`. Calculate its mean and median.
2. Replace the values list with `[9, 1, 3, 3]`. Run the file.
3. Check the last two lines: `Mean: 4.0` and `Median: 3.0`.
4. Try `[7]`. Both mean and median should be 7. Then try `[]`. The output should say `Mean: None` and `Median: None`; there is no observation to average.
5. Restore `[4, 6, 6, 12]`. Change only 12 to 120. Predict, then run: mean 34.0, median 6.0.

Record your results:

| Input | Predicted mean | Predicted median | Actual result |
|---|---|---|---|
| `[9, 1, 3, 3]` | | | |
| `[7]` | | | |
| `[]` | | | |
| `[4, 6, 6, 120]` | | | |

**Explain in one sentence:** why did the last change affect the mean so much more than the median?
