# Check the data file

Inspect accepted and rejected records.

Now use a supplied reader so you can focus on what it accepts and rejects.

1. Open `readings.csv` in your text editor. Do not change it yet. Row 1 is the header. Circle the blank value, `unknown`, and `130`.
2. Open `solution.py` from the same extracted folder and run it. Its checks run first, then it reports:

```text
Checks passed.
A: count=4 mean=7.00 median=6.00 modes=[6.0]
B: count=4 mean=3.75 median=4.00 modes=[0.0, 3.0, 5.0, 7.0]
Rejected row 9: missing value
Rejected row 10: not a number
Rejected row 11: outside finite 0-120 range
```

3. Find `B,0` in the CSV. It is accepted. Explain why it must not be grouped with the blank.
4. Save a **separate copy** as `readings-test.csv`. Replace the word `unknown` with `5`. In a saved copy of `solution.py`, change the filename at the bottom to `readings-test.csv`.
5. Run that copy. B should now have count 5, mean 4.00, median 5.00; only rows 9 and 11 should be rejected. Restore the original filename before comparing with the model again.

**Optional database experiment:** open `database_demo.py` in the same folder and run it. Expected lines are `A: SQL mean=7.00; Python mean=7.00` and `B: SQL mean=3.75; Python mean=3.75`. Underline `GROUP BY` in the query and explain what it does. No SQLite app or package installation is needed.
