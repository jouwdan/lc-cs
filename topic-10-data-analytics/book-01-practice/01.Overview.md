# Data, databases and analytics: practical

Allow 75–90 minutes. Prerequisites: lists, functions, CSV and basic SQL. Deliver a Python program, a cleaned-data summary, a query result and a 150-word interpretation. The reference implementation is `code/analytics/solution.py` in the course repository; attempt the design before reading it. Run it with `python3 code/analytics/solution.py` from the repository root.

The data describes fictional area measurements, not real pupils. Your question is whether area B has lower readings than area A in this sample. Write a hypothesis before calculating. List the field meanings and explain what a row represents. Predict how a blank value and a word in a numeric field should be handled. Keep source data intact; make rejection decisions visible. Success requires correct summaries and an honest limit on the conclusion, not proof that your prediction was right.
