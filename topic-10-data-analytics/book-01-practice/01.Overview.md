# 2. Practise: Data

Compare readings and check rejected records.

Compare two tiny datasets, then inspect three deliberately bad records.

**Plan:** two 40-minute sessions. Session 1: Steps 1–3 below and the next page. Session 2: run the CSV reader and explain the result. The SQL experiment is optional extension work.

## Get a working first result

1. [Download the starter pack](https://lc-cs.netlify.app/topic-10-data-analytics/book-01-practice/assets/analytics-starter.zip) and extract it into a folder called `readings-practice`. Keep `starter.py`, `readings.csv`, and `solution.py` together.
2. Open `starter.py` in the Python editor you used in Topic 06. In IDLE: **File → Open**, then **Run → Run Module (F5)**. You do not need a terminal or a GitHub account. If using a browser editor, the first experiment can be copied into it without the CSV.
3. Run it unchanged. You should see:

```text
Values: [4, 6, 6, 12]
Count: 4
Mean: 7.0
Median: 6.0
```

4. Save a copy as `my_readings.py`. Keep this page open beside your editor.

**Stop and check:** if your file ends in `.py.txt`, save it again with the `.py` extension. If Python cannot find the CSV later, check that the extracted files are in the same folder. Do not edit inside the ZIP.

Your first task is to predict one small change. You do not need to build a whole database today.
