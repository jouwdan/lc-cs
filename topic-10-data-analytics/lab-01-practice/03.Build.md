# Implement and query

Create `summarise(values)` that returns count, mean, median and modes. Use a sorted copy for the median, explicit empty handling and a frequency dictionary. Read the supplied CSV with `csv.DictReader`; convert each accepted measurement to `float`. Keep a list of rejections, including explanations.

Create an in-memory SQLite table with area and reading columns and insert accepted rows with parameterised statements. Query the average per area and sort the result by area. Compare the database averages with your Python summaries. Add a second table describing each area, with a primary key, and join it to readings if attempting the relational extension. Describe the data's journey from a line of text to a typed value to a stored row. Do not use string concatenation to build queries from input.
