# Explain the bits

Compare text encoding and compression.

## 1. Text

A friend says “UTF-8 always uses one byte per visible character.” Explain why that is wrong in one or two sentences.

**Check:** ASCII-range characters use one byte in UTF-8, but other characters can require more. Some visible symbols also contain multiple code points.

## 2. Compression

Which is more suited to run-length encoding: `AAAAAABB` or `ABABABAB`? Explain why.

**Check:** repeated runs in the first string can be stored with counts. The alternating string has short runs, so the counts can add overhead.
