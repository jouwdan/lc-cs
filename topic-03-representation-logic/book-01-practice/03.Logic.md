# Build a truth table

Check every input combination in a door rule.

## Core: a two-input door rule

A door opens only when a card is valid **and** a booking exists. Let C = valid card and B = booking.

1. Copy the table.
2. Put 1 in the output only when both inputs are 1.

| C | B | C AND B |
|---|---|---|
| 0 | 0 | … |
| 0 | 1 | … |
| 1 | 0 | … |
| 1 | 1 | … |

**Check:** outputs are **0, 0, 0, 1**.

Change AND to OR. **Check:** outputs become **0, 1, 1, 1**. Explain why OR would open the door without a card in one row.

## Higher Level: add a staff override

The card is still required. Either a booking **or** a staff override must also exist:

**open = C AND (B OR S)**

1. List all rows: 000, 001, 010, 011, 100, 101, 110, 111.
2. Add a column for **B OR S**.
3. Add the final column **C AND (B OR S)**.

**Check:** final outputs are **0, 0, 0, 0, 0, 1, 1, 1**.

Test the different rule `(C AND B) OR S` with C=0, B=0, S=1. It gives 1, so it wrongly opens without a card. Row 011 also exposes the error.
