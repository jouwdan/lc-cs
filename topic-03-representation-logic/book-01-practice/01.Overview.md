# 2. Practise: Binary & logic

Convert values and complete truth tables.

Convert numbers, calculate an image size and complete a truth table.

**You need:** paper; no Python is required. **Time:** two sessions of about 25 minutes. The <a href="https://tutors.dev/note/lc-cs/topic-03-representation-logic/note-01-concepts">worked lesson</a> is available if you get stuck.

1. **Represent:** convert numbers and calculate storage.
2. **Logic:** start with two inputs; try the three-input extension when ready.
3. **Explain:** explain one encoding and one compression choice.

**Done when:** your conversions include working, your storage answer includes units, and your truth table has every input combination. The notebook and whiteboard are optional ways to explore the same ideas.
