# Convert and calculate

Convert numbers and calculate a file size.

## 1. Convert 58 to eight-bit binary

Copy the place values: **128, 64, 32, 16, 8, 4, 2, 1**. Put 1 under each value you need to make 58.

**Hint:** start with 32. How much is left?

**Check after trying:** `32 + 16 + 8 + 2 = 58`, so **00111010**.

## 2. Convert to hexadecimal

Split your binary answer into two four-bit groups: `0011 1010`. Convert each group.

**Check:** 3 and 10; 10 is A, so **3A**.

Now convert **B3** to decimal. **Check:** `11 × 16 + 3 = 179`.

## 3. Add in binary

Add `0101 + 0111`. Show any carries. Check by adding the decimal values.

**Check:** **1100**, because `5 + 7 = 12`. Some four-bit additions need a fifth bit: `1111 + 0001 = 10000`.

## 4. Calculate an image size

An image is 80 pixels wide and 50 pixels high, with 24 bits per pixel. Ignore headers and compression.

Complete: `80 × 50 = ___ pixels`; `pixels × 24 = ___ bits`; `bits ÷ 8 = ___ bytes`.

**Check:** 4,000 pixels; **96,000 bits**; **12,000 bytes**.

**Optional:** repeat with one bit per pixel. **Check:** 4,000 bits = **500 bytes**. Only two pixel values are available, so the image cannot retain full RGB colour.
