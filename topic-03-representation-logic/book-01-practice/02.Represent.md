# Represent

Convert 58 to eight-bit binary and hex. Convert hex B3 to decimal. Add binary 0101 and 0111. Show each method and verify by decimal addition. Answers: 00111010, 3A, 179, and 1100. Explain why adding two four-bit values can require five bits even though this example does not.

Calculate the raw storage for an 80×50 RGB image at 24 bits per pixel. Answer: 96,000 bits, or 12,000 bytes before headers and compression. A correct number without units is incomplete. Extension: calculate the same image at one bit per pixel and explain what visual information is lost.
