## Question 1

**Answer: A service using internet infrastructure.** The web uses internet networks; other internet services are not web pages.

## Question 2

**Answer: Router.** Routing connects networks; switching commonly connects devices within a LAN.

## Question 3

**Answer: Resolving names to records such as IP addresses.** DNS locates information about a name; it does not itself deliver the requested web page.

## Question 4

**Answer: TCP.** TCP handles transport reliability and ordering; HTML and RGB are not transport protocols.

## Question 5

**Answer: Traffic in transit to the authenticated endpoint.** TLS protects the connection; the server can still host misleading content.

## Question 6

**Answer: Variation in packet delay.** Uneven timing affects real-time audio even when average capacity is sufficient.

## Question 7

**Answer: A password and a possession-based token.** Two knowledge secrets are the same factor type. Possession supplies a different type.

## Question 8

**Answer: Tested backups.** Recovery requires a usable copy and a working restoration process.

## Question 9

**Answer: What an identified user may do.** Authentication and permission decisions have different purposes.

## Question 10

**Answer: The central switch.** The central component is a shared dependency in the topology shown.

## Check the lab

The request travels from client through the local network/router to the server. DNS finds address information; TCP provides ordered reliable delivery; HTTPS protects the web connection.

A backup helps recover deleted bookings. Permissions restrict edits. Independently verifying a suspicious request helps detect phishing. A clear “not confirmed” message prevents a failed request being mistaken for a booking.

If you confused a control with its effect, finish this sentence: “Restricting editing to the organiser protects ___ because ___.” Check: **integrity**, because ordinary members cannot change other people's records.
