# Assess threats

For fictional booking data, make rows for accidental deletion, an unauthorised edit, a phishing request and network outage. In each row identify the affected goal, a relevant control, how it works and one limit.

Example: tested backups restore deleted bookings, improving recovery; they do not stop the original deletion. Permissions restrict changes, improving integrity; an authorised organiser can still make a mistake. MFA adds an independent factor; it does not replace careful handling of recovery codes.
