# Check and recover

Explain failures and choose a connection.

## 1. Choose the next check

| Situation | What would you check first? |
|---|---|
| The computer has no Wi-Fi connection | … |
| The host name cannot be found | … |
| The server responds but says the page is missing | … |

**Check:** local connection; DNS/name resolution; URL path or resource on the server. These are different failures.

## 2. Choose a connection

Choose wired or wireless for each, giving one reason:

- A fixed desktop lab.
- A sensor cart that moves between rooms.

**Example:** wired connections suit fixed desktops where stable access matters; Wi-Fi suits a moving cart, but coverage and interference must be checked.

## 3. Explain a star-network failure

One computer's cable breaks. Then consider the central switch failing.

**Check:** the first failure affects that computer's connection; the switch failure can affect all attached computers. Extra paths or equipment can improve resilience at added cost.
