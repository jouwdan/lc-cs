# Review and recover

Explain why a DNS failure and a wrong page path produce different investigations. A good answer checks name resolution separately from the requested server resource. Compare wired and wireless connectivity for a fixed computer lab and a moving sensor cart.

Peer-review with these criteria: all devices have roles; protocols are not confused with hardware; each control addresses its stated threat; no real personal data is collected. Model star-topology answer: one endpoint cable failure affects that endpoint, whereas central-switch failure can affect all connected endpoints. A resilient design can add redundancy, at additional cost and complexity.
