# Trace a web request

Draw the route from a client to a server.

## 1. Copy and label

```text
Laptop --Wi-Fi-- Access point -- Switch -- Router -- Internet -- Web server
                                  |
                              Desktop PC
```

Write one job beside each of the access point, switch, router and server. Add a second laptop connected to the access point.

**Check:** the access point connects wireless devices; the switch connects local devices; the router connects networks; the server supplies the booking page.

## 2. Follow a page request

Use the fictional URL `https://example.org/bookings`.

Put these actions in order: **display response; look up the host address; request the page**.

**Check:** look up the address → request the page → display the response. Cached address information may avoid a new DNS lookup.

On your diagram, add:

- **DNS:** finds address information for the host.
- **IP:** addresses and routes packets.
- **TCP:** provides the reliable ordered stream.
- **HTTPS:** protects the web connection using TLS.

Protocols are rules, not extra hardware boxes.

## Higher Level extension

A packet is lost during the download. Explain how TCP helps.

**Check:** it tracks delivery and can retransmit missing data, providing an ordered stream. In a live call, waiting too long for missing audio can make it useless; timely delivery matters too.
