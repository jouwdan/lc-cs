# Trace a request

Draw three clients, an access point, a switch, a router and an external web server. Label the roles even if a real household box combines them. Trace a request for an example resource and mark where DNS, IP, TCP and HTTPS contribute.

Core: give each role a one-sentence explanation. Higher Level: explain what happens when one packet is lost and why reliable ordering helps reconstruct a page. Contrast with a live call where late audio may be useless.
