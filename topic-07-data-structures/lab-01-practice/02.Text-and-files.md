# Process text and validate a file

Write `are_anagrams(first, second)` for the explicit rules “ignore spaces and case; retain other characters”. Test `Dormitory`/`Dirty room`, `abc`/`abd`, and `aab`/`abb`. Repeated characters matter. Empty strings match under this narrow contract; explain that choice instead of letting it be accidental.

Write a teaching check-digit function for non-empty ASCII digit strings. Return the sum of the digits modulo 10 as a single character. Test `472` → `3`, `005` → `5`, and rejection of `4X2`. Explain why transposing two digits can escape this scheme.

Read `scores.csv` with `csv.DictReader`. Require `name` and `score` columns, non-empty names, and integer scores from 0 to 100. Report the row number when a record is invalid. Calculate the median from the accepted list only if the entire input satisfies the contract; do not silently skip an invalid record and present a misleading class result.

Create a separate bad fixture with a missing header and another with score `101`. Confirm that each produces a useful error. Keep the supplied synthetic CSV unchanged so comparisons remain reproducible.
