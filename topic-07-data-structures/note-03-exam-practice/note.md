1. Read the exact wording and marks. Select the named skill from a multi-part question.
2. Spend about 10 minutes attempting it without the scheme; allow longer for a programming part.
3. Compare with the matching year and level scheme. Underline the missing step or concept.
4. Correct your answer in another colour, explain the correction, then retry a similar part without notes.

Use this record: **Question / My answer / Missing idea / Correction / Retry result**. Marking-scheme examples are not the only possible valid wording. Follow the question’s stated language, data and rules.
