# 2. Practise: Lists & files

Count values, compare words and read a file.

Build a count and median, compare two words, then read four fictional scores. Use Python 3 and no extra packages.

Plan **three sessions of 25–30 minutes**: Collections; Text and files; one optional extension. Learn sections 1–8 cover the core. The quiz also samples the extension ideas, so read their worked examples before taking it.

Save `list_lab.py`, `text_lab.py`, `csv_lab.py` and `scores.csv` in one folder. Use only the fictional data shown here.

Your functions must keep input lists unchanged. The median of no values is `None`, meaning no result. Keep a table of input / expected result / actual result beside your code.
