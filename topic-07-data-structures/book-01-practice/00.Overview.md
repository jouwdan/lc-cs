# Strings, lists, functions, and files: practical

Build small testable functions, then connect them to a CSV input file.

Allow two lessons of 50–60 minutes. Use Python 3 and the standard library only. Start with `values = [3, 5, 2, 4, 7, 7, 9]`. Keep the original list unchanged. The checked models and a fictional input file are in `code/topic-07-data-structures/`.

Core tasks are a count function, a median function, and a simple text transformation. The longer-run, frequency, and validation tasks are graduated extensions. Submit your functions, expected-answer table, and a short explanation of empty-input behaviour. Do not use actual pupil results or real passwords.

The practice dataset is synthetic. Its small size lets you calculate answers by hand and compare those answers with the program. Correctness on these examples is evidence, not proof that every possible input works.
