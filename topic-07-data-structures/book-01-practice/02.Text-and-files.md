```python
def are_anagrams(first, second):
    first = first.lower().replace(" ", "")
    second = second.lower().replace(" ", "")
    return sorted(first) == sorted(second)

print(are_anagrams("Dormitory", "Dirty room"))

```

## B. Read a small file (15–20 minutes)

1. Create `scores.csv` beside your Python files. Copy exactly:

```csv
name,score
Ava,42
Ben,67
Cian,90
Dara,67
```

2. Save the following complete example as `csv_lab.py` beside the working `list_lab.py`. `Path(__file__).with_name(...)` finds the CSV beside this program, even if you run it from another folder.

```python
import csv
from pathlib import Path
from list_lab import median

scores = []
with Path(__file__).with_name("scores.csv").open(newline="", encoding="utf-8") as source:
    reader = csv.DictReader(source)
    if reader.fieldnames != ["name", "score"]:
        raise ValueError("Expected name,score headers")
    for row in reader:
        if None in row or not row.get("name", "").strip():
            raise ValueError(f"Row {reader.line_num}: invalid name or extra fields")
        try:
            score = int(row["score"])
        except (TypeError, ValueError):
            raise ValueError(f"Row {reader.line_num}: score must be an integer")
        if not 0 <= score <= 100:
            raise ValueError(f"Row {reader.line_num}: score must be from 0 to 100")
        scores.append(score)
print(scores)
print("Median:", median(scores))
```

3. Run `csv_lab.py`. Expect `[42, 67, 90, 67]`, then `Median: 67.0`. The `.0` comes from averaging the two middle values, both 67.
4. Copy `scores.csv` to `bad_scores.csv`; change Ben's score to 101. In `csv_lab.py`, change only the filename to `bad_scores.csv`. Expect an error mentioning **Row 3** and the range 0–100. No median should print.
5. In the bad copy, restore 67 and change the header `score` to `mark`. Expect `Expected name,score headers`.
6. Restore the program to read `scores.csv` and rerun the valid case.

**Check:** parsing fields does not validate their values. Our small reader requires the two headers in this order; the fuller model also accepts additional named columns. Both reject invalid scores instead of silently dropping them.
