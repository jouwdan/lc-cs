## A. Check digits: `check_digits.py`

1. Start with the complete simple scheme:

```python
def check_digit(text):
    if text == "":
        raise ValueError("Use a non-empty digit string")
    total = 0
    for char in text:
        if char not in "0123456789":
            raise ValueError("Use ASCII digits 0-9")
        total = total + int(char)
    return str(total % 10)

print(check_digit("472"))
```

2. Expect `3`. Add calls for `005` and `742`; expect `5` and `3`. Try `4X2` separately and expect `ValueError`. Explain why the swap was missed.
3. For the weighted scheme, copy the function to `weighted_check_digit`. Use `enumerate(text)` to obtain both index and character: `for index, char in enumerate(text):`. Set weight 3 for an even index and 1 for an odd index, add `int(char) * weight`, and return `str((10 - total % 10) % 10)`.
4. Test `472`, `742`, `000`, `427`. Expect `5`, `9`, `0`, `5`. Name the swap still missed.

## B. Consecutive runs: `runs.py`

1. Copy this runnable starting point:

```python
def longest_run(values):
    if len(values) == 0:
        return []
    current = [values[0]]
    best = current.copy()
    for value in values[1:]:
        if value > current[-1]:
            current.append(value)
        else:
            current = [value]
        # Update best here when current is longer.
    return best

print(longest_run([3, 5, 2, 4, 7, 7, 9]))
```

2. The starting version returns `[3]`. Add `if len(current) > len(best):` and an indented `best = current.copy()`.
3. Expect `[2, 4, 7]`. Trace current and best after each value. Compare with the answer table.
4. Test `[]` → `[]`, `[9]` → `[9]`, `[3, 2, 1]` → `[3]`, and `[1, 2, 1, 2]` → the earliest `[1, 2]`. Explain why sorting first would change the problem.
