## B. Complete a count (10 minutes)

1. Create `list_lab.py`. Copy this runnable start:

```python
def count_above(values, limit):
    count = 0
    for value in values:
        if value > limit:
            count = count + 0  # Change this update.
    return count

if __name__ == "__main__":
    print(count_above([4, 8, 8, 2], 5))
```

2. Run it: the unfinished version prints 0. Change the update so it counts matching items. Expect 2.
3. Add three assertions inside the final block:

```python

assert count_above([5, 5], 5) == 0
assert count_above([8, 8], 5) == 2
```

These test empty input, the excluded boundary and duplicate matches. A successful assertion prints nothing.

## C. Complete the median (15 minutes)

1. Add this function **above** the `if __name__` block:

```python
def median(values):
    if len(values) == 0:
        return None
    ordered = sorted(values)
    middle = len(ordered) // 2
    if len(ordered) % 2 == 1:
        return ordered[middle]
    return None  # Replace with the average of the middle pair.
```

2. Use the lesson's even-length rule to replace the final line. Remember parentheses around the sum before dividing by 2.
3. In the demonstration block, print the median of each input below. Write expected results first:
