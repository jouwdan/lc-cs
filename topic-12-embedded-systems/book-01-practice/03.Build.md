# Separate measurement from decisions

Implement a conversion function and a controller function. Supply simulated readings first; test the functions without any board. Log raw value, converted level, enable state and output. Use the supplied sequence to verify hysteresis: relative levels 45, 29, 32, 39, 41 should produce off, on, on, on, off when enabled.

If hardware is available, connect only teacher-approved low-voltage components. Read several measurements at dry and wet references, record variability, and replace the synthetic constants. Connect the tested logic to actual inputs and an on-board display. For micro:bit, consult the official MicroPython pin and button documentation. Choose a sampling interval and explain its effect on responsiveness and energy. Keep a separate error indication for invalid measurements rather than substituting a fabricated normal value.
