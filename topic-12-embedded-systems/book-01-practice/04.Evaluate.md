# Test the boundaries

Try exact thresholds from both states.

1. Test levels `29.9, 30, 35, 40, 40.1` from both previous states. Predict before running:

| Level | Previously off | Previously on |
|---:|---|---|
| 29.9 | On | On |
| 30 | Off | On |
| 35 | Off | On |
| 40 | Off | On |
| 40.1 | Off | Off |

2. In a temporary call, try `relative_level(550, 800, 800)`. It should raise an error because the references are identical. Restore the working version afterwards.
3. Compare a single threshold with hysteresis for `[29, 31, 29, 31]`, starting off. The single-threshold rule `level < 30` switches at every reading. Hysteresis gives on, on, on, on. Explain the difference.
4. Complete two sentences: “My simulation checked ___.” “It did not check ___.” Name physical calibration or wiring in the second sentence.
5. Describe one readable error message and one output that does not rely only on colour.

**Optional extension:** choose a sampling interval for a real plant indicator and justify it. Explain how a long blocking delay could affect the enable button. Do not add smoothing until you have observed noise and considered the added delay.

Keep your calibration calculation, state table, and five-line test record. These are enough to explain your investigation clearly.
