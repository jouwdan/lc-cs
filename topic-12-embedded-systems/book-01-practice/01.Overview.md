# 2. Practise: Embedded

Simulate and test a plant warning.

Test the full decision path with invented readings. No board or electronics are required.

**Plan:** two 35–40 minute sessions. First calibrate and trace; then run the complete indicator and try boundary cases. Hardware is an optional supervised extension.

1. [Download the indicator starter pack](https://lc-cs.netlify.app/topic-12-embedded-systems/book-01-practice/assets/indicator-starter.zip) and extract it into `indicator-practice`.
2. Open `starter.py` in the Python editor from Topic 06. In IDLE choose **Run → Run Module (F5)**.
3. It should print:

```text
Raw 800 -> relative level 0.0
Raw 550 -> relative level 50.0
Raw 300 -> relative level 100.0
```

4. Save a copy as `my_indicator.py`.
5. Identify `dry = 800`, `wet = 300`, and the list of raw readings. These are fictional reference values. Do not call them measurements from a real sensor.

Your output is a warning on the screen. This practical does not switch a pump or any physical actuator.
