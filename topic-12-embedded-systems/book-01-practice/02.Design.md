# Calibrate and draw the state machine

Draw sensor → conversion → controller → display, with the digital enable input entering the controller. Create a connection table for any real board, including signal, power, ground and the permitted voltage range from its documentation. Have the teacher check it before connection.

Calculate converted values for raw readings 800, 550 and 300. Then define the controller: below 30 turns the warning on; above 40 turns it off; between the thresholds, including exact boundaries, preserves the prior state. Disabled monitoring forces the warning off. Draw the two states and labelled transitions. Plan tests for both directions through the middle band, equal calibration points, out-of-range ADC values and enable changes. Explain why the same reading can produce different outputs depending on history.
