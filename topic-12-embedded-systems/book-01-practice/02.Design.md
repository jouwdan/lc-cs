Convert a reading and predict the state.

1. Calculate the relative level for raw 655 using the formula in Learn. Show the numerator and denominator. Expected result: 29.
2. Add 655 to the starter's raw-reading list and run it. Check your calculation against `29.0`.
3. On paper, begin with warning **off**. Complete this table before opening the model:

| Level | Previous state | New state |
|---:|---|---|
| 45 | Off | |
| 29 | Your previous answer | |
| 32 | Your previous answer | |
| 39 | Your previous answer | |
| 41 | Your previous answer | |

Rules: below 30 means on; above 40 means off; 30–40 inclusive keeps the prior state.

4. Check your sequence: off, on, on, on, off.
5. Draw two circles labelled **Off** and **On**. Add the two threshold arrows and an arrow that turns monitoring off when disabled.
