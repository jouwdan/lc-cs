# Embedded systems: practical

Allow 75–90 minutes for the software investigation, plus supervised hardware time if equipment is available. Deliver a signal diagram, calibration record, controller program, test table and reflection. The standard-library simulator is `code/embedded/solution.py`; run it with `python3 code/embedded/solution.py`.

Use a display or indicator only. The digital input enables monitoring; the analogue input represents a sensor reading; the output warns when the relative level is low. In the simulator, use dry 800 and wet 300 as invented references, clearly labelled synthetic. For hardware, collect your own references under teacher supervision. Do not describe the calculated relative scale as certified soil-water percentage. Success requires both correct state transitions and an honest account of what was physically tested.
