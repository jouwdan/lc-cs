# Explain recursion and cost

Write iterative GCD using a pair update and recursive GCD using a base case. Trace `(48, 18)` by hand; expect 6. Test `(7, 0)`, `(0, 7)`, `(18, 48)`, and equal arguments. State how your implementation treats negative values and `(0, 0)`.

Compare the functions on a small fixed set. The aim is to establish equal results under the same contract, not to claim recursion is always better. Explain the stack cost and the shrinking second argument.

Add a counter for middle-item probes in binary search and one for inspected elements in linear search. On sorted lists of sizes 8, 16, and 32, search for a missing value larger than every item. Predict how counts grow before measuring. Do not confuse a probe with every individual Boolean operation in the code.

Conclude with a paragraph naming the input size, operation counted, precondition, and worst-case growth. Classroom rubric: correct traces (3), implementations and edge cases (4), preservation/contracts (1), reasoned comparison (2). Use the feedback after completing your own evidence.
