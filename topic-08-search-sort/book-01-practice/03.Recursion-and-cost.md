## A. Two versions of GCD

1. Save as `gcd_lab.py`:

```python
def gcd_iterative(a, b):
    a, b = abs(a), abs(b)
    while b != 0:
        a, b = b, a % b
    return a

print(gcd_iterative(48, 18))
```

The pair assignment calculates both new values from the old pair. This small exercise assumes integer arguments. The full model additionally checks their types.

2. Predict and run: expect 6. Trace the pairs until `(6,0)`.
3. Add `gcd_recursive(a,b)`. Start by making both values non-negative. If `b == 0`, return `a`; otherwise return `gcd_recursive(b, a % b)`.
4. Test both versions on `(7,0)`, `(0,7)`, `(18,48)`, `(6,6)`, `(-48,18)` and `(0,0)`. Expected results: 7, 7, 6, 6, 6, 0. Our contract defines the last result as 0.
5. Explain the base case and why the second argument gets smaller. Name the extra call-stack storage used by recursion.

## B. Count search work

from solutions import search_probes

for size in [8, 16, 32]:
