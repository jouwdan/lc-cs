# Trace sorting passes

Record the list after each sorting pass.

## Core: bubble sort (25 minutes)

1. Trace each neighbour comparison on `[7,2,5,1]`. Record the list after each full pass, not only after a swap. The first full pass ends at `[2,5,1,7]`.
2. Save this complete program as `bubble_lab.py`:

```python
def bubble_sort(values):
    result = values.copy()
    for end in range(len(result) - 1, 0, -1):
        changed = False
        for index in range(end):
            if result[index] > result[index + 1]:
                result[index], result[index + 1] = result[index + 1], result[index]
                changed = True
        if not changed:
            break
    return result

original = [7, 2, 5, 1]
print(bubble_sort(original))
print(original)
```

The pair assignment swaps neighbours using their old values. `end` shrinks the unsorted region. `changed` allows an early stop after a pass with no swaps.

3. Run it. Expect `[1, 2, 5, 7]`, then the unchanged original `[7, 2, 5, 1]`.
4. Add tests for `[]`, `[4]`, `[1,2,3]`, `[3,2,1]` and `[4,4,4]`. For each, compare the result with `sorted(original)` and check the input still equals a saved copy.
5. Add a temporary `print(result)` immediately after the inner loop to compare pass states with your paper trace. Remove it after checking.
