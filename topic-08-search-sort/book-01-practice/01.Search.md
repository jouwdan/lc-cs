## B. Binary search

2. Above your tests, add this runnable starting function:

```python
def binary_search(values, target):
    low = 0
    high = len(values) - 1
    while low <= high:
        middle = (low + high) // 2
        if values[middle] == target:
            return middle
        break  # Replace with the two interval-update branches.
    return -1
```

It currently finds only a match at the first midpoint. `break` safely ends the unfinished search.

3. Replace the `break` line with these four lines. Keep `if` and `else` aligned with the existing `if values[middle] == target:`: eight spaces from the left. Indent each update four spaces farther, for twelve spaces in total.

```python
        if target < values[middle]:

        else:

```
