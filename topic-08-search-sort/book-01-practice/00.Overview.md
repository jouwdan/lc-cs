# 2. Practise: Search & sort

Trace search, sort and recursion examples.

Work in **three 25–30 minute sessions**: Search; Sort; Recursion and cost. Use Python 3 and paper or a document named `algorithm-traces`.

Your contracts:

- Search returns a zero-based matching index, or -1 when absent.
- Binary search receives ascending data; any matching duplicate index is valid.
- Sorting returns a new list and preserves the original.

The core produces two search traces, a working search file and one bubble-sort trace/program. Recursion and extra sorts are extensions; read their worked lesson examples before the quiz.

Save the files named in each step in one folder. You may compare your result with Python's `sorted(...)`, but that call is a check, not your implementation of the requested sort.
