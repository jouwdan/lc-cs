# Compare sorting passes

On paper, show every full bubble-sort pass for `[7, 2, 5, 1]`. Then show every insertion-sort pass for the same input. Label the sorted suffix for bubble sort and the sorted prefix for insertion sort. These are different invariants even though the final list is identical.

Implement one of those algorithms, returning a copy. Test sorted, reverse-sorted, empty, singleton, and repeated-value inputs. Compare the result with `sorted(original)` and assert that `original` is unchanged. This checks the contract as well as the final ordering.

Next, trace selection sort on `[6, 3, 8, 2]`. If using two lists, remove the selected minimum from the source. Explain what goes wrong if you only copy it. Implement the in-place-within-a-copy variant as an extension.

For quicksort, partition `[7, 2, 5, 1, 5]` around 5 into less, equal, and greater lists. Preserve both copies of 5. Recursively sort the unequal partitions. Test an all-equal list to show that your recursion still terminates.
