# Searching, sorting, recursion, and efficiency: practical

Trace first, implement second, and compare a defined measure of work.

Allow two lessons of 50–60 minutes. Use Python 3, paper trace tables, and the checked code in `code/topic-08-search-sort/solutions.py`. Core work covers linear and binary search, then one elementary sort. Extension work covers all sort variants, recursive GCD, and complexity reasoning.

Our search contract returns a zero-based matching index or -1. Binary search receives an already sorted list. Sorting functions return a new list and preserve the original. State these rules in your own submission so tests have an unambiguous target.

Submit two search traces, at least one sort-pass table, working functions, and a comparison paragraph. Calling Python's built-in sort is useful as a test oracle but does not implement the sorting algorithm you are being asked to learn.
