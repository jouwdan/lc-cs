# Implement and test

Write a function `buses_needed(passengers, capacity=12)` that returns the count. A function is a named calculation; the next topics explain its syntax in depth. Start with the quotient, then use an `if` statement to add one when a remainder exists. Keep `input()` and `print()` outside this function so a test can call it directly.

The model contract rejects non-integers and invalid ranges with `ValueError`. If you have not learned exceptions, initially handle invalid input in the caller and discuss the model with your teacher. Never return a plausible bus count for a negative passenger number.

Turn your expected-answer table into assertions, for example `assert buses_needed(25) == 3`. Run every assertion, not just the first and last. Try changing `>` to `>=` in the remainder decision and confirm that a test catches the mistake; restore the correct code afterwards.

Next, trace a separate threshold counter on `[48, 72, 50, 31]`, threshold 50. Implement it as `count_at_least(values, threshold)`. Check an empty list and a list containing only threshold values. Explain the difference between a count and a sum.
