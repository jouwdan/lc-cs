## Optional: see it run in Python

1. Create `bus_booking.py` in your Python editor. Copy this complete program, or download [the same runnable example](https://raw.githubusercontent.com/jouwdan/lc-cs/main/code/topic-05-algorithms/bus_booking.py).

```python
passengers = 25
capacity = 12

if type(passengers) is not int or passengers < 0:
    print("Invalid passenger count")
else:
    buses = passengers // capacity
    if passengers % capacity > 0:
        buses = buses + 1
    print("Buses:", buses)
```

2. Save. Use the editor's Run button, or run `python3 bus_booking.py` in its folder. Expect `Buses: 3`.
3. Change only `passengers` to 24, then 0, then -1. Expect `Buses: 2`, `Buses: 0`, then `Invalid passenger count`.
4. Add actual results to your table. Python `//` means `DIV`; `%` means `MOD`; `print` displays output. The indented lines belong to the condition above them. Topic 06 explains this syntax properly.
