# 2. Practise: Algorithms

Design and test a bus-allocation plan.

Make a bus plan that another person can follow. **No coding experience is needed for the core work.**

Use paper or a document named `bus-plan`. Plan two 25-minute sessions: Design, then Implement and Explain. A Python 3 check is optional; all answers can be found by hand.

## Your rules

- Each bus has 12 available passenger seats. Drivers do not use these seats.
- Accept a whole-number passenger count of zero or more.
- Book the fewest whole buses. Zero passengers need zero buses.
- Report invalid input instead of inventing a bus count.

By the end, keep a specification, pseudocode or flowchart, and a table of expected results. Stop after the core Explain tasks if you are new to algorithms. Choose one puzzle extension in a later session.
