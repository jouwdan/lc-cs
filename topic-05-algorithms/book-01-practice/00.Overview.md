# Algorithms and computational thinking: practical

Build a precise bus-booking solution and explain why it works.

Allow 55–70 minutes. Work with a partner for the paper design, then produce your own code and explanation. You need paper, Python 3, and an editor. No packages or accounts are needed. Save your work as `bus_booking.py`; the checked model is in `code/topic-05-algorithms/solutions.py` in the repository.

Your contract is: the passenger count is a non-negative integer, capacity is a positive integer, and the result is the fewest whole buses that can carry everyone. Zero passengers need zero buses. Invalid values must be rejected. Start with capacity 12 and make the capacity parameter an extension after the core works.

Produce four items: a short specification, pseudocode or a flowchart, a completed trace table, and a tested program. A working answer without a record of your reasoning is incomplete for this exercise.
