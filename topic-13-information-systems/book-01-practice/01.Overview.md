# Interactive information systems: practical

Allow 90–120 minutes. Prerequisites: HTML basics, functions, database tables and queries. Deliver a requirements list, wireframe, working local site, test record and individual reflection. The complete reference is in `code/information-system/`. Run `python3 code/information-system/server.py --check` for checks, then `python3 code/information-system/server.py` and open `http://127.0.0.1:8000`.

The example contains only fictional book records. Its purpose is to demonstrate an actual browser-to-database interaction. It uses a loopback server and is not intended for public hosting. Before reading the implementation, write three user tasks and five measurable acceptance criteria. Include a user who operates the interface with a keyboard. Distinguish the database content from its visual presentation.
