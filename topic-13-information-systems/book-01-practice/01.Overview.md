# 2. Practise: Web apps

Run and change a library search.

Open a working local site, follow one search, then make one small change.

**Plan:** three 35–40 minute sessions: run and trace; edit one record; test the experience. You need Python 3 and a web browser. No database installation, hosting account, or GitHub knowledge is required.

1. [Download the working library starter](https://lc-cs.netlify.app/topic-13-information-systems/book-01-practice/assets/library-starter.zip) and extract it into a folder called `library-practice`.
2. Keep `server.py` and `index.html` together. Do not run them from inside the ZIP.
3. Open `server.py` in IDLE, or the Python editor used in Topic 06. Choose **Run → Run Module (F5)**. The message should say `Open http://127.0.0.1:8000`.
4. Leave the Python program running. Open [the local library](http://127.0.0.1:8000) in your web browser.
5. You should see “Find a library book”, a labelled search box, and **4 book(s) found.**
6. Type `river` and choose **Search books**. Expect two titles: **River Patterns — Available** and **The River Journey — On loan**.

**If it does not open:** use `http`, not `https`; check the Python program is still running; check both files are in the same folder. If the address is already in use, stop your earlier copy rather than starting another. In IDLE, **Shell → Interrupt Execution** or Ctrl+C stops this server.

Do not double-click `index.html` for this task. It needs the running Python server to query the database.
