# Change one record

Follow a change from database to page.

1. Stop the server with Ctrl+C or **Shell → Interrupt Execution**. Save a backup of `server.py`.
2. Find this record in `server.py`:

```python
(2, "The River Journey", 2, 0)
```

3. Change only the final `0` to `1`. It means the book is now available. Save, run the server again, and refresh the page.
4. Search `river`. Both books should now say **Available**. Explain why editing the database seed changed the page without changing its HTML.
5. Restore the original `0`, restart, and confirm **On loan** returns. Keep that original baseline for the next tests.
6. Open `index.html` in a text editor. Change only the `<h1>` wording to “Explore our fictional library”. Save and refresh. The data results should stay the same. This edit changes the page's structure/content, not the records.

**Optional Higher Level extension:** add a fictional category and one book that refers to its key. Predict its joined label, then test it. Do not add login or real pupil information. A nonexistent category key should fail the database's foreign-key rule.
