# Test as a user and a developer

Test an empty query, mixed letter case, no match, a title containing punctuation and input exceeding the server's length limit. Confirm the API gives JSON and an appropriate error response. In the browser, use Tab and Enter only, enlarge text, narrow the window and inspect the reading order. Stop the server and submit a search: the page should explain the failure.

Ask a partner to find an available book without instructions. Record the task outcome and one usability observation. Make one improvement and repeat the test. Submit your schema, screenshot or demonstration, test table and reflection linking the implementation to the original user needs. Explain the local server's limitations, including that it has no persistent editing or production deployment features.
