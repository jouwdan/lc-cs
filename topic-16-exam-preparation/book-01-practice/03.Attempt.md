# Try the question

Work independently and keep your attempt.

1. Start the timer and answer without the scheme. Label every subpart.
2. For a sort, record the list at the moments the question requests. For a Python trace, record variable changes separately from printed output.
3. At your checking point, look for skipped parts, loop endpoints, wrong units and output spacing.
4. Stop at the target time. Keep the first answer. Label any extra work “untimed” in another colour or copy.

**Checkpoint:** you have a dated first attempt, even if incomplete. Continue to **Repair**. Finding a specific gap gives you something useful to practise.

**If doing the optional programming route:** save the requested filenames, make one change at a time and run small tests. Record tests you actually ran. When output surprises you, trace a small example before rewriting a large section.
