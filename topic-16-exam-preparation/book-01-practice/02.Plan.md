# Plan the attempt

Choose the task, conditions and time.

1. Read the whole question. Note what each subpart asks you to produce: outputs, working, list states or an explanation.
2. For this short attempt, set a **10-minute study target without notes**. This is a learning choice, not an official question time allowance.
3. Reserve a few minutes at the end to check missed parts, labels and output order. If stuck, show the partial work you can explain, then move on.

**Checkpoint:** you can state what you are answering and when you will stop. Continue to **Attempt**.

**Optional full-paper route:** first read the cover and instructions for choices, marks, duration and materials.
