# 2. Practise: Testing

Fix a ticket calculation and record tests.

Find a reproducible fault, repair it and keep evidence. Use Python 3 and two sessions of about 30 minutes.

The fictional rule is **1200 cents each for 1–4 tickets**, **1000 cents each for 5–8 tickets**, and rejection of all other quantities. The discount applies to every ticket. The function returns integer cents; it does not store bookings or process payments.

Save a document `booking-tests` and files `faulty_booking.py`, `booking_lab.py`, `booking_input.py` in one folder. Keep the original faulty file unchanged so you can show what failed before the repair.

Your core result is a table of expected/actual totals, a corrected calculation and one text-input test. JavaScript tracing is a separate short extension.
