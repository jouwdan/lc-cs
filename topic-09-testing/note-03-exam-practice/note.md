2. **Next challenge:** [2025 Ordinary B Q14 (p. 13)](https://raw.githubusercontent.com/jouwdan/lc-cs/main/topic-17-past-papers/unit-2025/tutorial-exam-paper-section-aandb-ordinary-level-ev/exam-paper-section-aandb-ordinary-level-ev.pdf#page=13). After your attempt, use its [matching scheme p. 13](https://raw.githubusercontent.com/jouwdan/lc-cs/main/topic-17-past-papers/unit-2025/tutorial-marking-scheme-ordinary-level-ev/marking-scheme-ordinary-level-ev.pdf#page=13).

For each test, name an input/action and expected result. In the longer vending-machine question, start with the test-plan parts; other parts revisit additional topics.

1. Read the exact wording and marks. Select the named skill from a multi-part question.
2. Spend about 10 minutes attempting it without the scheme; allow longer for a programming part.
3. Compare with the matching year and level scheme. Underline the missing step or concept.
4. Correct your answer in another colour, explain the correction, then retry a similar part without notes.

Use this record: **Question / My answer / Missing idea / Correction / Retry result**. Marking-scheme examples are not the only possible valid wording. Follow the question’s stated language, data and rules.
