# Hardware for learning

An optional interview and a written task.

An optional interview and a short written alternative; neither is needed before starting the lesson.

Listen to balenaPodcast Episode 01 with Eben Upton for one design constraint affecting a learning device. Write the constraint and one hardware choice that might address it.

**Written alternative:** compare a cheap light logger with unclear pin labels against a device with clear labels and a built-in display. Give one advantage, one difficulty, and one test before choosing. Explain why price affects access but does not alone establish suitability. This is an original discussion task, not a transcript.
