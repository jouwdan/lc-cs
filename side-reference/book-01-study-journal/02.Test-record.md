# Test record

Predict, run and compare a small test.

1. Choose a small input. Write the expected result **before** running the code.
2. Run it and copy the actual result.
3. If it differs, keep the failed row. After a fix, retest it and one earlier passing case.

Example requirement for a new program: count values **strictly greater** than a limit and reject non-numeric values with `ValueError`.

| Test | Input | Expected result and reason | Actual result | Next action |
|---|---|---|---|---|
| Normal | `[4,8,2]`, limit 5 | 1: only 8 is above 5 | Fill after running | Pass or investigate |
| Boundary | `[5]`, limit 5 | 0: equality does not qualify | Fill after running | Pass or investigate |
| Invalid | `['bad']`, limit 5 | `ValueError` under this contract | Fill after running | Pass or investigate |
| Your own test | … | … | … | … |

Adapt the expected behaviour to **your** program's requirements. A test tells you what happened for that input; one passing test does not prove every case works.
