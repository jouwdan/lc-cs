# Course coverage

Match topics to official learning goals.

This course teaches the specification used for the **2020–2025** papers. Curriculum Online identifies this specification as applying to examinations through June 2028. The replacement curriculum is outside this course's coverage claim.

For daily study, follow the <a href="https://tutors.dev/course/lc-cs">topic route</a>. Use this page when you want to connect a topic to the official specification. The descriptions below are summaries, not substitutes for its wording.

## Which level should I study?

Start with the shared core. Try a labelled **Higher Level extension** when it matches your course or when you want an extra challenge. Ask your teacher about the depth expected for your level. The official specification uses bold words and clauses to show differences: a whole topic is not automatically Higher Level only.

Extensions include heuristics, Turing machines, detailed CPU components, combined gates, deeper protocol work, quicksort, recursion, efficiency, aspects of testing, relational database work and agent-based emergence. Optional enrichment is labelled separately.

## Find the learning area

| Official outcomes | Learning area | Topics | What you practise |
|---|---|---|---|
| 1.1–1.10 | Computational problem solving | 05, 08, 11 | Break down a problem, trace states and justify an algorithm |
| 1.11–1.18 | Society, history, AI, usability, careers | 02, 04, 13, 14 | Explain effects on people and evaluate a design |
| 1.19–1.23 | Design, teamwork, communication | 09, 13, 15 | Write requirements, improve a version and explain your contribution |
| 2.1–2.4 | Abstraction and modularity | 05–09, 11 | Choose relevant details and divide code into functions |
| 2.5–2.10 | Algorithms | 05–08 | Write pseudocode, trace code and compare efficiency |
| 2.11–2.15 | Computer systems | 02–04, 12 | Explain systems, data representation, logic and networks |
| 2.16–2.18 | Data | 03, 06, 07, 10 | Choose types/encodings and clean data reproducibly |
| 2.19–2.22 | Testing and evaluation | 09, 15, 16 | Predict results, record tests and explain improvements |
| 3.1–3.3 | Interactive information systems | 10, 13, 15 | Build a usable site backed by a database |
| 3.4–3.7 | Analytics | 07, 10, 15 | Ask a question, clean data, graph results and state limits |
| 3.8–3.10 | Modelling and simulation | 11, 15 | State rules, repeat experiments and explore agents |
| 3.11–3.14 | Embedded systems | 12, 15 | Use digital/analogue inputs, calibrate and test outputs |

The three strands—principles, core concepts and applied work—connect throughout the course.
