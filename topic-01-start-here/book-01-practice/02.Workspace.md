# Save and run

Create a Python file and check its output.

Allow about 15 minutes. A Python file is a text file whose name ends in `.py`.

## 1. Type and save

Create a new file and type this exact line:

```python
print("Ready to learn")
```

Save it as **hello.py** in `cs-practice`. Avoid `hello.py.txt`.

## 2. Run the saved file

Use your editor's **Run** command. If your class uses a terminal, open it in the `cs-practice` folder and run:

```sh
python3 hello.py
```

On Windows, your setup may use `py hello.py` or `python hello.py`. Use the command your teacher has shown you.

**Expected output:**

```text
Ready to learn
```

`print` displays the message inside the quotation marks. The quotation marks themselves are not printed.

## 3. Make one change

Replace the message with `I can run Python`. Save and run again.

**Check:** the new output must be `I can run Python`.

| Problem | Try this |
|---|---|
| Old message appears | Save the file and check that you ran the same file you edited. |
| Python reports a syntax error | Check both quotation marks and both brackets. Use straight quotes as shown. |
| File not found | Check the filename and which folder your terminal is in. |
| Python command not found | Use your editor's Run command or ask your teacher to check the setup. |

Write the editor action or command that worked. Keep it for the next lab.

## 4. Keep a backup

Copy the saved file to your normal school backup location. Open that copy and check the code is there. Keep the original. Two copies on the same disk do not protect you if that disk fails.
