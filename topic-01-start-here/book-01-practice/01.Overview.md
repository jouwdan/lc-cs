# 2. Practise: Start here

Save, run and change your first Python file.

Make a small program, change it and keep one useful study note.

**You need:** Python 3 in your school's editor, plus paper or a notes file. **Time:** two sessions of about 25 minutes. No previous coding is needed.

## Before you start

1. Make a folder called `cs-practice`.
2. Open your Python editor. If you do not have one, ask your teacher which environment to use.
3. Use **Next** to create your first file.

If you cannot run Python today, write down the code and predict its output. Do the study-log steps, then return to running the file later.

**Done when:** you can save and run a file, change its message, and write one specific next study task.
