# Plan a session

Choose one short session and a clear task.

## 1. Pick a time

Choose one 25-minute session this week. Write down when and what you will do.

Example: “Tuesday after school: read Topic 02 sections 1–4, then draw the library computer.”

## 2. Use this simple plan

- **5 minutes:** recall one idea with notes closed.
- **15 minutes:** read an example and try a task.
- **5 minutes:** check and write one correction.

You can add more sessions later. One clear plan is enough to start.

## 3. Check you can continue

Can you save and run `hello.py`, explain its output and find your next task? If so, this lab is complete. Keep your file and one study-log row.
