# Keep a correction

Record one mistake and a useful next step.

You only need a short table. An **error log** records what went wrong and how you corrected it.

## 1. Try without looking up the answer

1. What will `print("Hello")` display?
2. Does one correct program run prove the program works for every possible input?
3. What should you check if your edited message does not appear?

## 2. Check

1. `Hello`, without quotation marks.
2. No. It only shows the result for the inputs you tested.
3. Save the file and make sure you ran the file you edited.

## 3. Write one row

| My attempt | What I learned | Next task |
|---|---|---|
| The old message appeared. | I had run an unsaved version. | Save, then run a different message. |

Use your own example. If everything worked, write one explanation you could give a classmate: for example, what “save” and “run” mean.

**Optional starting check:** can you explain what an OS does, convert 9 to binary, or predict `2 + 3 * 4`? It is fine to leave these blank. You will learn them in Topics 02, 03 and 06.
