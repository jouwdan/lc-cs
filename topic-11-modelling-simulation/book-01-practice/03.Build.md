# Run the experiment

Repeat a random model with fixed seeds.

1. Open `solution.py` from the extracted pack. This version creates the event lists using probabilities.
2. Find the call `simulate(10, 0.6, 0.5, 7)`: the arguments are **minutes, arrival probability, service probability, seed**.
3. Run the file unchanged. The first remaining-queue line should be `[0, 0, 0, 1, 1, 1, 2, 2, 2, 2]`.
4. Run again. It should match because the seed is unchanged.
5. In a copy, change only seed 7 to 8. The result may change. Keep both outputs.
6. Return to the unchanged model. Read the two 20-seed comparison lines. They report the **mean queue over time, averaged across runs**; they are not mean waiting times.

**Predict before changing:** what happens if service probability is 1.0? Under these rules, at most one arrival and certain service leave nobody waiting after each minute. What happens if it is 0? Every arrival stays.

**Optional Higher Level extension:** add arrival timestamps to a separate copy and calculate waiting time when a person leaves. State whether people still waiting at the end are included. Do not overwrite the core model while exploring this.
