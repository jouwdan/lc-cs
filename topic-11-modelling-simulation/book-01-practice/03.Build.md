# Run controlled experiments

Implement one simulation function with parameters and a local seeded random generator. Return the complete queue history, arrivals and served count so invariants can be checked. Calculate the final, maximum and mean remaining queue without confusing any of them with waiting time.

Run twenty seeds for service probabilities 0.5 and 0.8, keeping arrival probability and duration constant. Save each run's parameters and summary. Produce a table comparing the mean and spread of the outputs. Do not reset the seed every minute. **Higher Level:** add two servers or explicit arrival timestamps, then explain precisely how your revised model measures waiting time. Compare the revised rules with the original rather than assuming that more code always means a better model.
