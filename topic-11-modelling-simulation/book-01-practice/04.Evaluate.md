# Check rules and limits

Test the model and explain its assumptions.

1. Check the first line says `Checks passed.` The supplied model has tested the hand trace, empty duration, extremes, repeatability, and the arrivals-minus-served invariant.
2. In a copy, try `simulate(5, 1.2, 0.5, 1)`. It should reject the impossible probability. Restore a valid value.
3. Write this four-line result card:

```text
I changed: service probability from 0.5 to 0.8.
I kept fixed: arrivals 0.6, 120 minutes, seeds 0–19, update order.
I observed: [copy the two measured means, with units of people].
A limitation is: [one missing real-world factor].
```

4. Add one sentence distinguishing verification from validation. Your tests verify the rules; actual help-desk observations would help validate the model.
5. Name one useful real measurement, such as how many arrivals occur per minute at different times.

**Optional agent task:** draw two pedestrians approaching a doorway. Give each a position and a movement rule. Describe one collective pattern that might emerge. State your update order and how a blocked agent behaves.

Your final evidence is the event trace, two experiment results, and the short result card. No long report or graphing package is required.
