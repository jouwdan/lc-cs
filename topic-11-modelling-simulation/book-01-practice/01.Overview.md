# 2. Practise: Models

Predict and run a small queue model.

Start with a result you can check on paper. Add random events in the second session.

**Plan:** two 40-minute sessions. No hardware, extra Python packages, or Jupyter installation is needed.

1. [Download the queue starter pack](https://lc-cs.netlify.app/topic-11-modelling-simulation/book-01-practice/assets/queue-starter.zip) and extract it to `queue-practice`.
2. Open `starter.py` in your Python editor. In IDLE use **Run → Run Module (F5)**. It runs without keyboard input.
3. Check the output:

```text
Remaining queue: [1, 0, 1, 1, 0]
Arrivals: 3
Served: 3
```

4. Save a copy as `my_queue.py`.
5. Read the two event lists at the bottom. A `1` means an event happens; a `0` means it does not.

The rules are **arrival → service if possible → record**. A service opportunity does not remove a person from an empty queue.
