# Specify and trace

Create a table separating initial conditions, state variables, parameters and outputs. Use a zero initial queue, 120 minutes, arrival probability 0.6 and service probability 0.5 as the baseline. Both probabilities must lie between 0 and 1 inclusive; duration must be a non-negative integer.

Hand-trace five minutes with arrivals `[1, 0, 1, 1, 0]` and service successes `[0, 1, 0, 1, 1]`. Predict remaining queues `[1, 0, 1, 1, 0]`. Identify the rule that prevents service making the queue negative. Choose tests for no arrivals, no service, zero minutes and invalid parameters. Decide whether zero-duration mean queue should be `None` or an error, and document that contract.
