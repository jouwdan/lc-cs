# Modelling and simulation: practical

Allow 75–90 minutes. Build a model of a fictional help desk, using no personal data. Deliver the model specification, a hand trace, a tested Python program and a short comparison of scenarios. The reference is `code/simulation/solution.py`; run with `python3 code/simulation/solution.py` from the course repository.

In each minute, at most one visitor arrives. An available server may complete service with a specified probability. Arrivals happen first, service second, and the remaining queue is recorded last. Write these rules in your own words. Explain why both arrivals and service must be represented. Predict the effect of faster service before running the code. Success is a reproducible and appropriately limited explanation, not an impressive-looking graph.
