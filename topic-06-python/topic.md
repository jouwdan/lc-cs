# 06 · Python fundamentals

Read, trace, and write small Python programs with reliable input, decisions, and loops.

## Study route

Read the concepts, predict the worked examples, complete the lab, take the quiz, then use the feedback to correct your reasoning. Finish with the recap slides.

## Prerequisites

Complete Topic 05. Install Python 3 or use the school-approved Python environment.

## Success criteria

- Choose suitable basic types and convert input explicitly.
- Evaluate arithmetic, comparison, and Boolean expressions.
- Write selection and repetition that handle boundaries correctly.
- Distinguish syntax, runtime, and logical errors.
- Modify an existing program incrementally and preserve working evidence.

Core tasks support both levels. Extension tasks add depth for Higher Level; they do not replace the core. Work at the level specified by your teacher and the current syllabus.
