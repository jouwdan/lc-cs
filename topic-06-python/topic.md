# 06 · Python

Learn Python through small working programs.

**Before you start:** Complete Topic 05. Open Python 3 in your school editor and make a folder for your saved files.

**Suggested pace:** Session 1 (25–30 min): Learn sections 1–5 and one-ticket lab. Session 2 (30 min): input and group totals. Session 3 (optional, 20 min): sentinel entry.
