# Extend, test, and explain

Extension: create a score-entry loop with sentinel -1. Real scores are whole numbers from 0 to 100. Count accepted scores and display their total. Check the sentinel before adding a value. Reject other negative values and values over 100. Define what happens if the first input is -1: both count and total should remain zero.

Compare `for age in ages` with a `while` loop. The former fits a known collection; the latter fits an input process whose repetition count is not known in advance. Explain where the controlling state changes in your `while` loop.

Finish by classifying three deliberately supplied mistakes: missing a colon, dividing by zero, and resetting the total inside the loop. For each, state how you would detect it and what evidence proves the correction.

Submit your expected/actual table and a short explanation of two boundary decisions.
