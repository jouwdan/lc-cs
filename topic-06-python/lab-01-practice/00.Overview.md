# Python fundamentals: practical

Practise input conversion, boundary decisions, and repeated calculations with a fictional pricing rule.

Allow 60–75 minutes. Use Python 3 and save `tickets.py`. Work first with fixed test values, then add an input interface. The checked model is in `code/topic-06-python/solutions.py`.

A club ticket costs €8.00 for ages below 16, €12.00 for ages 16–64 inclusive, and €9.00 for ages 65 and above. Accept whole-number ages from 0 to 120. This is an invented practice rule. Store prices as integer cents (800, 1200, 900) and format only when displaying them.

Deliver a prediction table, three incremental versions or an edit log, and test evidence. Core work covers a single ticket. Extension work calculates a group total from a list of ages and handles invalid input without losing earlier working code.
