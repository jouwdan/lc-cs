Predict outputs and calculate one ticket.

## A. Run a short expression check

```python

```

2. Write six predicted lines. Run the file using the editor, or `python3 expressions.py`.
3. Check against `3`, `2`, `11`, `14`, `34`, `7`. The fifth output is text. Explain one difference between text and numbers.

## B. Build a function, starting with a runnable file

1. In `tickets.py`, copy the following. It already handles invalid values and child tickets. It deliberately returns the wrong price for other valid ages.

```python
def ticket_price_cents(age):
    if type(age) is not int or not 0 <= age <= 120:
        raise ValueError("Age must be a whole number from 0 to 120")
    if age < 16:
        return 800
    return 0  # Replace this line with the remaining price branches.

if __name__ == "__main__":
    for age in [0, 15, 16, 64, 65, 120]:
        print(age, ticket_price_cents(age))
```

`type(age) is not int` rejects non-integers. `raise ValueError` signals invalid input. The last block runs the demonstration when you run this file directly; it does not run when another file imports the function.

2. Run it. The first two prices should be 800; the remaining zeroes show the unfinished rule.
3. Replace the final `return 0` with `elif age < 65: return 1200` and an `else` returning 900. Put each return on an indented line under its branch.
4. Run again. Expected output:

```text
0 800
15 800
16 1200
64 1200
65 900
120 900
```

5. Add `assert ticket_price_cents(16) == 1200` and `assert ticket_price_cents(65) == 900` inside the demonstration block. They are silent when correct.
6. Temporarily change `< 16` to `<= 16`. Run, observe the failed age-16 assertion, then restore `< 16`.

**Checkpoint:** one working function, two boundary assertions and six correct printed prices. Keep `tickets.py`; the next step imports it.
