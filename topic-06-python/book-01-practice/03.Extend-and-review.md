## Optional: score entry with a sentinel

A sentinel is a stop value outside the valid score range. Here scores are whole numbers 0–100, and **-1 means finish**.

1. Save this runnable starting version as `score_entry.py`:

```python
count = 0
total = 0
while True:
    try:
        score = int(input("Score (0-100), or -1 to finish: "))
    except ValueError:
        print("Enter a whole number.")
        continue
    if score == -1:
        break
    if not 0 <= score <= 100:
        print("Score must be from 0 to 100.")
        continue
    total = total + score
    # Add the count update here.
print("Count:", count)
print("Total:", total)
```
