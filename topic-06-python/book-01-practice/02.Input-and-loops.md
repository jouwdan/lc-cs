# Add input and repetition

Ask for an age as text. Convert it with `int`, catch `ValueError`, and display a clear message for text such as `sixteen` or `16.5`. Then check the valid range. Explain why conversion alone does not reject -1.

Print the amount using two decimal places. The internal result is still cents; the display can use `price / 100` with an f-string. Check that 800 displays as `8.00`. Do not silently substitute zero for a failed conversion.

Now process a group: `[12, 16, 70]`. Initialise a total before a loop, call the price function for each age, and accumulate the returned cents. Predict the exact total before running. A group with no people should produce zero, not an uninitialised variable error.

Record a trace with columns age, price, and running total. In a temporary copy, move the accumulator initialisation inside the loop. Explain the wrong result and why the program still runs. This is a logical error, not a syntax error.

For input practice, write a separate prompt that repeats after an invalid entry and stops only after obtaining a valid age. Avoid a bare `except`; catch the error you expect.
