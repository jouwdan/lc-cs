# Input and group totals

Read an age and add tickets in a loop.

## A. Ask for an age

1. Save this complete file as `ticket_input.py` beside your working `tickets.py`:

```python
from tickets import ticket_price_cents

try:
    age = int(input("Age (0-120): "))
    cents = ticket_price_cents(age)
except ValueError:
    print("Enter a whole-number age from 0 to 120.")
else:
    print(f"Price: EUR {cents / 100:.2f}")
```

`from tickets import ...` loads your function from `tickets.py`. If Python cannot find it, check both files are saved in the same folder and the names match.

2. Run `ticket_input.py` six times. Try `15`, `16`, `65`, `-1`, `16.5` and `sixteen`.
3. Expect prices `8.00`, `12.00`, `9.00` for the first three, each preceded by `Price: EUR `. The last three should show the whole-number age message.
4. Explain why `-1` converts successfully but still fails validation, while `sixteen` fails during conversion.

## B. Add several prices

1. Save as `group_tickets.py` in the same folder:

```python
from tickets import ticket_price_cents

ages = [12, 16, 70]
total = 0
for age in ages:
    price = ticket_price_cents(age)
    total = total + price
    print(age, price, total)
print(f"Group total: EUR {total / 100:.2f}")
```

2. Predict the running total after each person. Run and compare:

```text
12 800 800
16 1200 2000
70 900 2900
Group total: EUR 29.00
```

3. Change `ages` to `[]`. Expect only `Group total: EUR 0.00`.
4. Restore the three ages. In a copy, move `total = 0` inside the loop before the addition. Predict the incorrect final total, then test. It becomes `9.00` because each iteration forgets earlier prices. Restore the working version.

**Optional:** wrap the input section in `while True:` and place `break` after the successful price display. Invalid input should repeat the prompt; a valid age should finish. Test `sixteen`, then `16`, in one run.
