# 2. Practise: Python

Build a ticket calculator step by step.

Build one working piece at a time. Use Python 3. You need the Learn sections on functions before step 01 and input conversion before step 02.

Suggested sessions: **25 minutes** for expressions and a single ticket; **30 minutes** for input and a group total. Return later for the optional sentinel task.

| Age | Fictional price |
|---|---:|
| 0–15 | 800 cents (€8.00) |
| 16–64 | 1200 cents (€12.00) |
| 65–120 | 900 cents (€9.00) |

Only whole-number ages from 0 to 120 are valid. Save separate files so each stage stays runnable: `expressions.py`, `tickets.py`, `ticket_input.py`, then `group_tickets.py`. Save them **in the same folder** so imports work.

Keep a small table: input / expected result / actual result. You will calculate expected answers before running the code.
